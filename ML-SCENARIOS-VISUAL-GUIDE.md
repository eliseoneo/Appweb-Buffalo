## 📊 Chart Types by Scenario

### Area Charts (Trends):
- **Excellent:** Upward slope (35 → 85)
- **Balanced:** Flat line (38 → 42)
- **Warning:** Slight decline with variations
- **Critical:** Sharp crash (70 → 32)
- **Growth:** Explosive growth (100 → 220)
- **Decline:** Steady decline (180 → 78)

### Donut Charts (Distributions):
- **Excellent:** 85% positive slice dominates
- **Balanced:** 68% positive, balanced
- **Warning:** 58% positive, 30% negative
- **Critical:** 68% NEGATIVE dominates (inverted!)
- **Growth:** Conversions increase
- **Decline:** Normal distribution but declining

### Bar Charts (Comparisons):
- **Excellent:** High values across all
- **Critical:** Disconnect reasons spike
- **Growth:** Capacity vs demand analysis
- **Decline:** Root cause breakdown
